# A Biologically Inspired Echo State Network with Spike-Frequency Adaptation, Short-Term Depression, and Synaptic Delays

> Working manuscript draft. Figures are generated by `scripts/make_paper_figures.m`
> into `results/figures/paper/`. The core analytical result (Proposition 1) is
> derived in `src/algorithms/Jacobian/J_eff_notes.md`.

## Abstract (draft)

We introduce the Membrane Echo State Network (MESN), a rate-coded excitatory-
inhibitory reservoir that incorporates three biological mechanisms absent from
standard Echo State Networks: multi-timescale spike-frequency adaptation (SFA),
presynaptic short-term depression (STD), and delayed inhibitory feedback. We
prove a sufficient condition, expressed directly in terms of the adaptation and
depression parameters, under which the network satisfies the Echo State
Property (ESP), and we show empirically that increasing adaptation drives the
largest Lyapunov exponent toward zero, placing the reservoir at the edge of
chaos. We further show that (i) multi-timescale SFA broadens the memory and
timescale spectrum, (ii) the network is temporally invariant (shift-equivariant)
and robust to input time-warping, and (iii) adaptation induces a phase-advance
(predictive) component in the representation. As a reservoir, only the linear
readout is trained ("learning on the edges"), matching the locality of learning
in biology, yet the MESN matches or exceeds a non-adaptive reservoir on standard
benchmarks. Finally, we relate the conservative ESP bound to the non-normality
of the recurrent weight matrix, measured by the Kreiss constant.

## 1. Introduction

- Reservoir computing / ESN background; the ESP and the edge of chaos.
- What adaptation adds to a network: SFA and STD as gain-control / negative
  feedback; delays and E-I structure (Dale's law).
- Biological motivation: local learning (only the readout / "edges" is trained);
  multi-timescale processing; predictive (phase-advancing) coding.
- Contributions:
  1. A sufficient, parameter-explicit condition for the ESP (Proposition 1).
  2. Empirical demonstration that adaptation tunes the Lyapunov exponent to ~0.
  3. Multi-timescale memory, temporal invariance, and phase advance.
  4. Task performance with local (readout-only) learning.
  5. Non-normality (Kreiss) as the source of conservativeness in the ESP bound.

## 2. Model (MESN)

State `S = [a_E; a_I; b_E; b_I; x]`. Dynamics (`src/SRNN_reservoir.m`,
delayed variant `src/SRNN_reservoir_DDE.m`):

- `x_eff = x - c .* sum_k a_k`, `r = phi(x_eff)`, `s = b .* r`.
- `tau_d dx/dt = -x + W s + u`.
- `da_k/dt = (r - a_k)/tau_{a,k}` (multi-timescale SFA).
- `db/dt = (1-b)/tau_rec - b r/tau_rel` (STD).
- Dale-structured `W` scaled by spectral abscissa; inhibitory delay `lags`.

Configuration and defaults: `src/configs/default_MESN_config.m`. Nonlinearity:
piecewise sigmoid with bounded derivative `0 <= phi' <= 1`
(`src/nonlinearities/piecewiseSigmoid.m`).

## 3. Adaptation guarantees the Echo State Property (Result 1)

**Effective Jacobian.** Freezing the slow variables gives the fast subsystem
Jacobian `J_eff = (1/tau_d)(-I + W G)`, `G = diag(b_j phi'(x_eff_j))`
(`src/algorithms/Jacobian/compute_J_eff.m`), validated against the full and
finite-difference Jacobians by `scripts/verifyJacobianConsistency.m`.

**Proposition 1 (sufficient ESP condition).** If
`||W||_2 * max_j b_j phi'(x_eff_j) < 1` over the reachable set, the reservoir is
a contraction (`mu_2(J_eff) < 0`) and the ESP holds, with rate
`nu = (1 - ||W||_2 g_max)/tau_d`. STD lowers `b`, and SFA lowers `phi'(x_eff)`;
both shrink `g_max`, so sufficient adaptation restores the ESP even when `W` is
scaled into the chaotic regime. Proof and coupled (non-quasi-static) statement:
`src/algorithms/Jacobian/J_eff_notes.md`.

**Empirical phase diagram (Fig 2).** `scripts/run_esp_phase_diagram.m` sweeps
`(level_of_chaos, adaptation-scale)`, marks where `verify_echo_state_property`
holds, and overlays the analytical boundary `||W||_2 g_max = 1`. Prediction: the
empirical ESP region contains the analytical (conservative) region and expands
with adaptation.

## 4. Stability and the edge of chaos (Result 2)

- `scripts/run_parameter_grid.m` sweeps `tau_d`, SFA `c_E`/`c_I`, STD, and
  `level_of_chaos`, recording the largest Lyapunov exponent (Benettin) and/or
  full spectrum (QR), the dynamical regime, the ESP, memory capacity, and the
  spectral/non-normality properties of `W`.
- Claim: increasing `tau_d` and adaptation pushes the largest Lyapunov exponent
  toward zero from below; STD accelerates the return to the stable regime after
  perturbations. (Figs 3.)
- **Supporting: non-normality.** `src/algorithms/stability/compute_nonnormality.m`
  computes departure from normality, numerical abscissa, the Kreiss constant,
  and the transient-growth envelope for `W` and `J_eff`. The gap between
  `||W||_2` and `rho(W)` (non-normality) explains why Proposition 1 is
  conservative; we report the correlation of non-normality with memory and the
  ESP margin (Fig 4). Non-normal reservoirs can show larger transient
  amplification and, empirically, improved memory.

## 5. Multi-timescale representation, temporal invariance, phase advance (Result 3)

`scripts/run_timescale_invariance.m`:

- **Timescale spectrum:** memory capacity (`compute_memory_capacity`), Fisher
  memory curve (`compute_fisher_memory_curve`), MI-lag curve
  (`compute_MI_lag_curve`), and decay fits (`fit_memory_decay`) across the number
  of SFA timescales `n_a_E`. Claim: more timescales -> broader/longer memory.
- **Temporal invariance:** shift-equivariance
  (`src/algorithms/info/measure_shift_equivariance.m`) and time-warp robustness
  of a trained readout. Claim: the reservoir map is time-invariant and
  degrades gracefully under input dilation.
- **Phase advance:** `src/algorithms/info/compute_phase_advance.m` shows a shift
  of the feature-input cross-correlation peak toward negative lag (features lead
  the input) when adaptation is enabled -- a substrate for prediction. (Fig 5.)

## 6. Reduced-model bifurcation (Result 4)

Using only the 4-variable mean-field E-I-STD-DDE model
(`src/models/meanfield_EI_STD_DDE.m`),
`scripts/run_meanfield_adaptation_bifurcation.m` shows how adaptation strength
and inhibitory delay move the system across a Hopf-like boundary into the stable
fixed-point (useful) regime. No large-network continuation is attempted. (Fig 6.)

## 7. Task performance with local learning (Result 5)

`scripts/run_benchmarks.m` trains only the ridge readout on NARMA-10/20,
Mackey-Glass (one-step + autonomous rollout), and Lorenz-63, comparing
adaptation ON vs OFF. This isolates "what adaptation adds" and instantiates the
"learning is local; the ESN learns only on the edges" point. (Fig 7.)

## 8. Discussion

- Adaptation as self-organized criticality / automatic gain control for the ESP.
- Non-normality vs stability trade-off; Kreiss constant as a design knob.
- Predictive coding via phase advance; multi-timescale memory.
- Limitations: conservative bound; reduced-model-only bifurcation; rate coding.
