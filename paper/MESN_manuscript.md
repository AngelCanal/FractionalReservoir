## Abstract (draft)

We introduce the Membrane Echo State Network (MESN), a rate-coded excitatory-
inhibitory reservoir that incorporates three biological mechanisms often studied
separately in reservoir computing: multi-timescale spike-frequency adaptation
(SFA), short-term depression (STD), and a scalar inhibitory delay. This draft
reports **implementation validation** (state layout, input isolation, ODE
Jacobians, ODE Lyapunov controls, leakage-free readout) and a **preregistered**
mechanism-ablation protocol. Publication mechanism-advantage claims require the
completed ≥30-seed paired table (gate G7). For the non-delayed ODE we report a
**quasi-static fast-gain diagnostic** on the frozen-`(a,b)` subsystem and,
separately, **empirical state-convergence rates** under driven inputs (three
classifications; never “ESP proven”). ODE Lyapunov exponents are validated on
known linear controls; DDE Lyapunov/Jacobian analyses are unsupported. As a
reservoir, only the linear readout is trained. Terminology: multi-timescale
SFA/STD delayed reservoir — not a fractional derivative unless a separate
approximation analysis is supplied.

## 2. Model (MESN)

State `S = [a_E; a_I; b_E; b_I; x]`. Dynamics (`src/SRNN_reservoir.m`,
delayed variant `src/SRNN_reservoir_DDE.m`):

- `q(E) = x(E) - a_E*c_a_E(:)`, `r = phi(q)`, resources `b` when STD enabled.
- `tau_d dx/dt = -x + W (b.*r) + u`.
- Multi-timescale SFA and optional STD; Dale-structured `W`; optional scalar
  inhibitory delay.

Configuration: `src/configs/default_MESN_config.m`. Support matrix:
`docs/validation/SUPPORT_MATRIX.md`.
