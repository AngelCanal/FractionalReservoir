# A Biologically Inspired Echo State Network with Spike-Frequency Adaptation, Short-Term Depression, and Synaptic Delays

> Working manuscript draft. Figures are generated by `scripts/make_paper_figures.m`
> into `results/figures/paper/`. The quasi-static fast-gain diagnostic is
> documented in `src/algorithms/Jacobian/J_eff_notes.md` (not a full ESP theorem).

## Abstract (draft)

We introduce the Membrane Echo State Network (MESN), a rate-coded excitatory-
inhibitory reservoir that incorporates three biological mechanisms absent from
standard Echo State Networks: multi-timescale spike-frequency adaptation (SFA),
presynaptic short-term depression (STD), and delayed inhibitory feedback. For
the non-delayed ODE we report a **quasi-static fast-gain diagnostic** on the
frozen-`(a,b)` subsystem and, separately, **empirical state-convergence rates**
under driven inputs (three classifications; never “ESP proven”). ODE Lyapunov
exponents are validated on known linear controls; DDE Lyapunov/Jacobian analyses
are unsupported. We further study (i) multi-timescale SFA memory spectra,
(ii) held-out time-warp generalization versus baselines, and (iii) response-lag
structure. As a reservoir, only the linear readout is trained. Non-normality of
continuous-time generators (Kreiss) is reported only for stable ODE Jacobians.

## 1. Introduction

- Reservoir computing / ESN background; the ESP and the edge of chaos.
- What adaptation adds to a network: SFA and STD as gain-control / negative
  feedback; delays and E-I structure (Dale's law).
- Biological motivation: local learning (only the readout / "edges" is trained);
  multi-timescale processing; response-lag structure of adapted features.
- Contributions:
  1. Scope-limited quasi-static fast-gain diagnostic for the ODE frozen subsystem,
     plus empirical convergence classifications (not an ESP theorem for MESN/DDE).
  2. Validated ODE Lyapunov spectrum tools; empirical adaptation–stability sweeps.
  3. Multi-timescale memory, shift equivariance, and held-out warp generalization.
  4. Task performance with local (readout-only) learning.
  5. Non-normality (Kreiss) of stable continuous-time generators vs memory.

## 2. Model (MESN)

State `S = [a_E; a_I; b_E; b_I; x]`. Dynamics (`src/SRNN_reservoir.m`,
delayed variant `src/SRNN_reservoir_DDE.m`):

- `x_eff = x - c .* sum_k a_k`, `r = phi(x_eff)`, `s = b .* r`.
- `tau_d dx/dt = -x + W s + u`.
- `da_k/dt = (r - a_k)/tau_{a,k}` (multi-timescale SFA).
- `db/dt = (1-b)/tau_rec - b r/tau_rel` (STD).
- Dale-structured `W` scaled by spectral abscissa; inhibitory delay `lags`.

Configuration and defaults: `src/configs/default_MESN_config.m`. Nonlinearity:
piecewise sigmoid with bounded derivative `0 <= phi' <= 1`
(`src/nonlinearities/piecewiseSigmoid.m`).

## 3. Empirical convergence and a quasi-static fast-gain diagnostic (Result 1)

**Effective Jacobian (ODE only).** Freezing the slow variables gives the fast
subsystem Jacobian `J_eff = (1/tau_d)(-I + W G)`,
`G = diag(b_j phi'(x_eff_j))` (`src/algorithms/Jacobian/compute_J_eff.m`).
This is a **quasi_static_fast_gain_diagnostic**: local, trajectory-dependent,
and **not** a theorem for the full ODE (dynamic `a,b`) or any DDE. Delayed
configs raise `MESN:DelayedJacobianUnsupported`. See
`src/algorithms/Jacobian/J_eff_notes.md`.

**Diagnostic contour (not an ESP theorem).** The level set
`||W||_2 * g_max = 1` with trajectory-sampled `g_max` is plotted only as a
sufficient condition for the **frozen** `a,b` subsystem at sampled gain, unless
a uniform reachable-set bound is supplied. It must not be labeled “ESP holds.”

**Empirical phase diagram (Fig 2).** `scripts/run_esp_phase_diagram.m` sweeps
`(level_of_chaos, adaptation-scale)` and colors cells by the three empirical
classifications from `verify_echo_state_property`:
`empirically_contracting_on_test_set`, `not_contracting_on_test_set`,
`inconclusive`. For DDE runs, only these empirical diagnostics are reported
(no finite-dimensional LLE or Jacobian contour). A full incremental-stability
derivation remains an expert-only future task
(`docs/validation/FUTURE_INCREMENTAL_STABILITY.md`).

## 4. Stability and the edge of chaos (Result 2)

- `scripts/run_parameter_grid.m` sweeps `tau_d`, SFA `c_E`/`c_I`, STD, and
  `level_of_chaos`, recording ODE Lyapunov exponents (Benettin/QR; DDE
  unsupported), dynamical regime, empirical convergence classification, memory
  capacity, and non-normality of continuous-time generators (`J_eff`).
- Claim (empirical, ODE): increasing `tau_d` and adaptation tends to push the
  largest Lyapunov exponent toward zero from below. (Fig 3.)
- **Supporting: non-normality.** `src/algorithms/stability/compute_nonnormality.m`
  requires a stable continuous-time generator (spectral abscissa < 0). Kreiss
  estimates are grid-based; boundary contact invalidates the estimate.
  Non-normal reservoirs can show larger transient amplification and, empirically,
  improved memory (Fig 4).

## 5. Multi-timescale representation, temporal invariance, response lag (Result 3)

`scripts/run_timescale_invariance.m`:

- **Timescale spectrum:** memory capacity (`compute_memory_capacity`), MI-lag
  curve (`compute_MI_lag_curve`), and decay fits (`fit_memory_decay`) across the
  number of SFA timescales `n_a_E`. Claim: more timescales -> broader/longer
  memory. (The historical Fisher-memory routine is quarantined; see
  `docs/validation/FISHER_MEMORY_STATUS.md`.)
- **Temporal invariance / held-out warp generalization:** shift-equivariance
  (`src/algorithms/info/measure_shift_equivariance.m`) and held-out time-warp
  evaluation (`evaluate_time_warp_generalization.m`). Readout is trained only
  on the unwarped training realization; NRMSE is reported on disjoint inputs
  and warp factors versus persistence, linear-history, and ordinary-ESN
  baselines. A score worse than baseline is a negative result, not invariance.
- **Response lag:** `src/algorithms/info/compute_response_lag.m` reports the peak
  of `R(k)=corr(feature(t),input(t+k))`. Under this convention `k<0` means the
  feature lags (associates with past input); `k>0` is apparent future association
  and, for white-noise drive, is treated as a leakage/alignment warning rather
  than validated prediction. (Fig 5.)

## 6. Reduced-model dynamical regime sweep (Result 4)

Using only the 4-variable mean-field E-I-STD-DDE model
(`src/models/meanfield_EI_STD_DDE.m`),
`scripts/run_meanfield_adaptation_bifurcation.m` performs a **dynamical regime
sweep** by time integration: adaptation strength and inhibitory delay are
gridded, trajectories are classified (fixed point vs oscillatory), and a regime
map is reported. This is **not** a bifurcation diagram. A bifurcation diagram
requires equilibrium/periodic-orbit continuation, branch detection, and
stability information (see `docs/validation/FUTURE_DDEBIFTOOL_CONTINUATION.md`).
Variance heatmaps must not be presented as branch diagrams. (Fig 6.)

## 7. Task performance with local learning (Result 5)

`scripts/run_benchmarks.m` trains only the ridge readout on NARMA-10/20,
Mackey-Glass (one-step + autonomous rollout), and Lorenz-63, comparing
adaptation ON vs OFF. This isolates "what adaptation adds" and instantiates the
"learning is local; the ESN learns only on the edges" point. (Fig 7.)

## 8. Discussion

- Adaptation as empirical gain control for state convergence (not a proven ESP).
- Non-normality vs stability trade-off for stable continuous-time generators.
- Response-lag structure under adaptation; multi-timescale memory.
- Limitations: quasi-static diagnostic is not a full MESN/DDE theorem; DDE
  Lyapunov/Jacobian unsupported; reduced-model regime sweep only (no
  continuation bifurcation analysis yet); rate coding. Expert future work:
  `docs/validation/FUTURE_INCREMENTAL_STABILITY.md`.
